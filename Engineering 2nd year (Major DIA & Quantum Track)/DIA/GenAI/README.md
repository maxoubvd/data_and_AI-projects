## 2. Projets personnels

### Jarvis Agent

Création de A à Z d'un agent autonome spécialisé dans le code. Sous forme d'extension VS Code (publiée sur Open VSX) mais également d'outil en ligne de commande (CLI publiée sur npm). Ce projet est un projet open-source [jarvis-agent](https://github.com/maxoubvd/jarvis-agent)


### Coach App

Création d'une application mobile (apk) personnelle pour m'aider à structurer mes entrainements de Course-à-pied, cyclisme et natation (Triathlon), améliorée grâce à des analyses IA et un RAG.

### Chatbot

Création d'un chatbot à jour de l'état de l'art de ce qui se fait : 
- Frontend via OpenWeb UI
- Backend comprenant un Serveur MCP Outlook et Garmin
